Mission

The Civis Project exists to make youth living conditions visible, comparable, and trackable over time — the same way tools like the CIVICUS Monitor made civic space visible on a single map. Where CIVICUS tracks the health of civil society, this project tracks the health of childhood and adolescence itself: whether a young person growing up in a given country has access to healthcare, education, economic opportunity, and physical safety.

The long-term goal is not just a map, but a longitudinal record — a way to see whether conditions for young people in a given country are improving or declining, year over year, grounded in real, publicly available UNICEF data rather than anecdote or headline-driven perception.

Why an absolute, benchmark-anchored score

Country scores in this project are not ranked relative to each other. A country's score doesn't move just because another country's data improved or worsened. Instead, every indicator is scored against a fixed, real-world benchmark — usually a UN Sustainable Development Goal target or a WHO/UNICEF reference threshold — so that a score of 70 means the same thing this year as it will in five years.

This trade-off costs some visual range early on (most countries may cluster in a similar band rather than spreading across the full color scale), but it's the only approach that lets the map honestly answer the question that actually matters: is this country's youth getting a better or worse deal over time?

The composite formula

Each country's composite score is a weighted average of four category scores:

Health and Education are weighted highest, both because they reflect UNICEF's own core priorities and because they have the deepest, most reliable data coverage across countries. Economic Opportunity is weighted lowest because UNICEF has no dedicated indicator for it — this project uses child poverty and youth NEET rates as a proxy, which is one step removed from what it's actually meant to measure.

Each raw UNICEF indicator is converted to a 0–100 score using:

indicator_score = 100 × (raw_value − floor) / (ceiling − floor) ​ clamped to the range [0, 100] (for "lower is better" indicators, floor and ceiling are inverted)

Category scores are the average of their available indicator scores. The composite score is the weighted average of the four category scores, using the weights above.

Handling missing data: If a country is missing an entire category, that category is dropped and the remaining weights are scaled up proportionally so they still sum to 100%. Alongside the composite score, a data completeness percentage is shown (categories with real data ÷ 4), so a score built on partial data is never presented with the same confidence as a fully-supported one.

Update cadence

Scores are intended to be refreshed annually, matching the pace at which most underlying UNICEF indicators are actually updated. Floors and ceilings are treated as fixed reference points and are not adjusted during a normal annual refresh — they should only change if an underlying benchmark itself changes (for example, if a future SDG framework revises a target), so that scores stay comparable across years.

What this project is not

This is an independent project. It is not affiliated with, endorsed by, or produced by UNICEF — it draws on UNICEF's public datasets and applies its own composite methodology on top of them. Scores currently displayed on the map are placeholder values for prototyping and do not yet reflect real UNICEF data.
